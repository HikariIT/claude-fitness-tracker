# 1. Schema, migration, DAL read, docs
**Decisions:** D1, D4, D5, D6, D14

Goal: add the `food_portions` table, add portion snapshot columns to `food_components` and `diary_entries`, generate the migration, expose a cached read, and update the docs. No UI and no service changes here.

## Steps
1. `src/db/schema/foods.ts`: add the table below **after** `foods` and before `foodComponents`. Import `uniqueIndex` from `drizzle-orm/pg-core` as well.
```ts
// Named portion sizes of a food (D1), e.g. "Tablespoon" = 15 g. Order = sortOrder (form row order).
export const foodPortions = pgTable(
  "food_portions",
  {
    id: integer().primaryKey().generatedAlwaysAsIdentity(),
    foodId: integer()
      .notNull()
      .references(() => foods.id, { onDelete: "cascade" }),
    name: text().notNull(),
    grams: numeric({ precision: 7, scale: 1, mode: "number" }).notNull(),
    sortOrder: integer().notNull(),
    ...timestamps,
  },
  (t) => [
    uniqueIndex("food_portions_food_name_unique").on(t.foodId, sql`lower(${t.name})`),
    check("food_portions_grams_positive", sql`${t.grams} > 0`),
  ],
);
```

6. `src/server/dal/foods.ts`: add
```ts
export type FoodPortion = typeof foodPortions.$inferSelect;

/** Every portion row (tag "foods"), ordered by foodId, then sortOrder. The UI groups them by foodId. */
export async function listFoodPortions(): Promise<FoodPortion[]> {
  "use cache";
  cacheTag("foods");
  return db.select().from(foodPortions).orderBy(asc(foodPortions.foodId), asc(foodPortions.sortOrder));
}
```
