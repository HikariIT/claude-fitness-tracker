# 4. Locale layout, redirect, placeholder pages, not-found
**Decisions:** D1, D3, D5, D12, D13, D16

Goal: move the app under `src/app/[locale]/`, render the shell (header with app name and language toggle, nav tabs, notebook sheet, toaster), and add the 5 placeholder pages plus not-found handling. Remove the create-next-app starter files. Pages are thin: they only compose components (no DB access).

Context from earlier subtasks (signatures to use; do not re-read the components):
- `@/i18n/routing`: `routing` (`locales: ["pl","en"]`, `defaultLocale: "pl"`).
- `@/i18n/navigation`: `Link`, `redirect({ href, locale })`.
- `next-intl`: `hasLocale`, `NextIntlClientProvider`, `type Locale`. `next-intl/server`: `setRequestLocale(locale)`, `getTranslations(namespace)` / `getTranslations({ locale, namespace })`.
- `src/app/fonts.ts`: `nunito`, `patrickHand` (use `.variable`).
- Components: `AppNav` (no props, client), `LanguageToggle` (no props, client), `NotebookSheet({ children, className? })`, `PageHeader({ title, description?, actions? })`, `EmptyState({ title, description?, icon? })` from `@/components/layout/*`; `Toaster` from `@/components/ui/sonner`; `buttonVariants` from `@/components/ui/button`.
- Message keys: `app.name|description`, `pages.<profile|foods|planner|workouts|balance>.title|description`, `common.emptyTitle|comingSoon`, `notFound.title|description|back`.
- Next 16: `params` is a Promise. Use the global helper types `LayoutProps<"/[locale]">` and `PageProps<"/[locale]/profile">` (generated by Next, no import). `cacheComponents` is on, so do not call `new Date()`, `cookies()` or `headers()` in these files.

## Steps
1. Delete `src/app/layout.tsx` and `src/app/page.tsx`. Delete the unused starter assets `public/next.svg`, `public/vercel.svg`, `public/file.svg`, `public/globe.svg`, `public/window.svg`. Keep `src/app/favicon.ico`, `src/app/globals.css` and `src/app/fonts.ts`.

2. `src/app/[locale]/layout.tsx` (root layout, D13):
```tsx
import type { Metadata } from "next";
import { notFound } from "next/navigation";
import { hasLocale, NextIntlClientProvider } from "next-intl";
import { getTranslations, setRequestLocale } from "next-intl/server";
import { routing } from "@/i18n/routing";
import { nunito, patrickHand } from "../fonts";
import "../globals.css";
// + AppNav, LanguageToggle, NotebookSheet, Toaster imports

export function generateStaticParams() {
  return routing.locales.map((locale) => ({ locale }));
}

export async function generateMetadata({ params }: LayoutProps<"/[locale]">): Promise<Metadata> {
  const { locale } = await params;
  if (!hasLocale(routing.locales, locale)) return {};
  const t = await getTranslations({ locale, namespace: "app" });
  return { title: { default: t("name"), template: `%s · ${t("name")}` }, description: t("description") };
}

export default async function LocaleLayout({ children, params }: LayoutProps<"/[locale]">) {
  const { locale } = await params;
  if (!hasLocale(routing.locales, locale)) notFound();
  setRequestLocale(locale);
  const t = await getTranslations("app");
  return (
    <html lang={locale} className={`${nunito.variable} ${patrickHand.variable} h-full`}>
      <body className="min-h-full">
        <NextIntlClientProvider>
          <div className="mx-auto w-full max-w-5xl px-4 py-6">
            <header className="mb-4 flex items-center justify-between gap-4">
              <span className="font-hand text-3xl text-primary">{t("name")}</span>
              <LanguageToggle />
            </header>
            <AppNav />
            <NotebookSheet>{children}</NotebookSheet>
          </div>
          <Toaster />
        </NextIntlClientProvider>
      </body>
    </html>
  );
}
```

3. `src/app/[locale]/page.tsx`: `const { locale } = await params; redirect({ href: "/planner", locale: locale as Locale });` (D3).

4. Five placeholder pages: `src/app/[locale]/{profile,foods,planner,workouts,balance}/page.tsx`. They all have the same shape (example for profile; use icons `User`, `Apple`, `CalendarDays`, `Dumbbell`, `Scale` from `lucide-react`):
```tsx
export async function generateMetadata({ params }: PageProps<"/[locale]/profile">): Promise<Metadata> {
  const { locale } = await params;
  const t = await getTranslations({ locale: locale as Locale, namespace: "pages.profile" });
  return { title: t("title") };
}

export default async function ProfilePage({ params }: PageProps<"/[locale]/profile">) {
  const { locale } = await params;
  setRequestLocale(locale as Locale);
  const t = await getTranslations("pages.profile");
  const common = await getTranslations("common");
  return (
    <>
      <PageHeader title={t("title")} description={t("description")} />
      <EmptyState icon={User} title={common("emptyTitle")} description={common("comingSoon")} />
    </>
  );
}
```

5. Not-found handling:
   - `src/app/[locale]/[...rest]/page.tsx`: `export default function CatchAll() { notFound(); }` (from `next/navigation`), so unknown paths like `/pl/xyz` render the localized not-found inside the shell.
   - `src/app/[locale]/not-found.tsx` (non-async, uses `useTranslations("notFound")`): `PageHeader` with title/description and a `Link href="/planner"` (from `@/i18n/navigation`) styled with `buttonVariants({ variant: "outline" })` showing `t("back")`.
